# Home-Assistant-Add-ons (Martin Kistler)

Eigenes Add-on-Repository für Home Assistant. Einbinden:
**Einstellungen → Add-ons/Apps → Store → ⋮ → Repositories** → `https://github.com/MartinKist/ha-addons` hinzufügen.

| Add-on | Beschreibung |
|---|---|
| [Claude Code](claude-code/) | Claude Code Remote Control auf `/config` (Session aus der Claude-App bzw. claude.ai/code), Login über Web-Terminal (Ingress) |

Updates: Version in `<addon>/config.yaml` erhöhen, Eintrag in `<addon>/CHANGELOG.md`, committen. HA zeigt das Update nach „Nach Updates suchen“ an.
